# Giants card reference and artwork

The Giants catalogue contains 81 named Skystones, including rank variants. Names, elements, and directional pip counts were transcribed from the community reference in NicMineDude/Skystones-JAVA-Edition at commit `7c9282237973099d8fa3975b4572c2d810a6e2f4`:

https://github.com/NicMineDude/Skystones-JAVA-Edition/blob/7c9282237973099d8fa3975b4572c2d810a6e2f4/src/main/resources/cardBase.csv

80 PNG card images come from that same revision's `assets/baseStones` directory. The reference has no Bark Demon image, so that card uses this application's original illustrated golem. The catalogue follows this community transcription; it has not been independently verified against every in-game card. CSV columns north/south/east/west are mapped to this application's north/east/south/west order. `None` becomes Neutral. The original Conquertron retains its four 4-pip edges.

Skylanders, its character names, and original game artwork belong to Activision and Toys for Bob. This is an independent fan recreation, not an official product. The eight added creature illustrations and adventure content were created for this application. No game code from the reference projects was included.

Earlier community projects consulted to check the rules and sample edge orientations:

- https://github.com/DanielStein15/skystones
- https://github.com/4ubiks/skystones

The application also uses React, Vite, Lucide, html-to-image, DM Sans, and Fraunces under their respective package licenses.

# Slay the Spire event reference

The event coverage list was checked against event identifiers in TranslateTheSpire/spanish_translation at revision `fb04988fb30f48c117422cd91d313a3cf54ebd6d`:

https://github.com/TranslateTheSpire/spanish_translation/blob/fb04988fb30f48c117422cd91d313a3cf54ebd6d/events.json

The catalogue covers 51 playable event names from that reference, plus adaptations of the unused Thinking with Puddles scene, Neow’s opening blessing, and the Spire Heart scene. Proceed Screen is a navigation interface and is excluded. All encounter prose, game rules, card illustrations, and implementation in this project were written for Skystones; no Slay the Spire code, event dialogue, or artwork was copied. Slay the Spire and its event names belong to Mega Crit. This is an independent fan adaptation.
